Where might a model's reasoning branch? Each token is shaded by a heuristic: logit entropy (how unsure the model is about its next token), the outcome probe (a linear probe on layer-18 hidden states predicting how much forcing a different token would change the final answer), or their product. Click any token to see what else the model considered there.
